# R4 方法说明：退让目标的条件保持

> 方法已冻结于 `3c5e44f3bd4186b4f5a3ec012b1a8d9fd728d617`。已完成一次72新实例×5方法评估及360回合原始指标复算。

## 先理解问题、方法和证据

**剩余问题之一是目标选择、实际机动与目标保持不协调。** R3的Relay160提供了有价值的路线空间，但几何上可行的目标不一定能及时改变实际运动。一个具体冲突是：风险规则刚发出退让目标，普通路线规则下一秒又把目标改回前进方向。低层控制器只执行了一秒退让指令，就失去了完成机动的机会。

**本轮保留“实际运动触发退让 + 退让目标条件保持”。** 正常航行继续使用Relay160。只有近10秒净接近障碍、朝当前目标的进度非正、且短期匀速外推显示余量不足时，才尝试向最近障碍的反方向发出目标。选点后给该退让目标一个60秒响应窗口；几何失效、距离超限或接近目标时可以提前退出。没有给所有普通目标强加最短保持时间，没有重训控制器，也没有使用真风或环境副本。

**依据来自实际闭环。** 22个离线分支核对了相同的决策前记录状态与待执行旧动作；较早改点在部分失败过程中确实能改变完整任务结局。随后，条件保持的配对消融暴露了上述“下一秒撤销退让”的冲突。通道案例中，保持版937秒安全到达，无保持版652秒侵入；保持版最小余量仅4.78米，因此它是局部有效证据，不是安全证明。

## 1. 继承什么，新增什么

继承完整静态地图、实体外60米真实安全边界、25米A*网格，以及Relay的500米路线前视、100米接力距离、550米目标距离限制。原14维SAC-LSTM @7200、归一化、动作约束、动力学、真实历史重编码和 `t→t+1` 目标生效时序均不变。

Relay160的“160米”是**额外规划留量上限**，不是新的真实安全半径。实际规划留量仍为

\[
m_t=\min\{160,\max[0,\min(c(p_t),c(g))-5]\}.
\]

这里的 $g$ 是最终终点，$c$ 是相对真实安全边界的余量。膨胀地图无路时，原Relay回退到原安全地图。这个回退不表示执行风险消失。R4的运动触发条件不随上述留量回退而自动归零。

新增状态很少：复用Relay最近11个位置记录；保存最后一次风险尝试时刻、退让目标及保持截止时刻。正式输入只有当前位置、航向、当前目标、已知路线和时钟。新增规则实际使用的是世界坐标位置、目标、地图和因果位置历史。航向继续用于原低层；R4不读取风标签、RNG、未来状态、离线分支结果或Actor内部特征。

```text
当前状态、已知地图、当前目标、过去10秒位置
          │
          ├── 普通Relay提案 ──────────────────────────┐
          │                                           │
          ├── 已在退让保持窗口且退出条件未触发？──是── 保留退让目标
          │                    │否                    │
          └── 运动风险条件满足且距上次尝试≥60秒？      │
                        │否：采用普通提案              │
                        │是                           │
                 检查500m / 250m退让目标              │
                   │可行：选退让目标                  │
                   │都不可行：采用普通提案            │
                   └──────────────────────────────────┘
                             │
      t时刻已算出的旧目标动作照常执行一个物理步
                             │
          t+1应用新目标，按真实历史重编码，继续低层控制
```

普通规划本身抛出无路异常时，沿用原runner的终止行为。流程图省略了这一继承异常分支；条件保持不会绕过该异常。

## 2. 触发和选点公式

令障碍 $i$ 的圆心为 $o_i$，实体半径为 $r_i$。原评价排除半径是 $R_i=r_i+60$。定义

\[
c(p)=\min_i(\|p-o_i\|-R_i),\qquad
C(p,q)=\min_i\{\operatorname{dist}(o_i,[p,q])-R_i\}.
\]

$C$ 是线段的几何余量，不能当作实际帆船轨迹包络。空地图余量为无穷，新增触发不会启动。用10秒因果位移计算

\[
\hat v_t=(p_t-p_{t-10})/10,\quad
u_t=\hat v_t^\top(q_t-p_t)/\|q_t-p_t\|,\quad
\hat C_t=C(p_t,p_t+60\hat v_t).
\]

$\hat v_t$ 单位为米/秒；$u_t$ 是朝当前目标的有符号进度，单位相同；$\hat C_t$ 单位为米。匀速外推只是报警线索，不是控制器或风场预测器。至少积累11个位置样本后，才判断

\[
\mathcal R_t=[c(p_t)<160]\land[c(p_t)<c(p_{t-10})]
\land[u_t\le0]\land[\hat C_t<80].
\]

满足条件且距上一次风险尝试至少60秒时，取最近的安全边界所对应的障碍

\[
i^*=\arg\min_i(\|p_t-o_i\|-R_i),\quad
q(L)=p_t+L\frac{p_t-o_{i^*}}{\|p_t-o_{i^*}\|}.
\]

按 $L=500,250$ 米的顺序尝试。候选必须在地图范围内、原安全地图线段可行，并能从候选连通最终终点。采用第一个合格目标，不另设综合评分。两者均不可行时，记录失败尝试并采用普通Relay提案。选择失败不表示风险已解除，也不假定帆船可以刹停或全向逃逸。

这里的退让候选没有再次叠加160米留量，因为触发时当前位置可能已经没有这份空间；它仍须满足原60米安全边界的几何检查。实际轨迹仍可能越界，评价规则不会放宽。

## 3. 为什么需要“条件保持”

若在 $t_s$ 选中退让目标，将保持截止时刻设为 $t_s+H$，$H=60$ 秒。之后仅在以下条件同时成立时，覆盖普通Relay提案，继续原退让目标：

- 当前实际生效目标就是该退让目标；
- 当前决策时刻 $t<t_s+H$；
- 目标距离在 $100<\|q-p\|\le550$ 米内；
- 当前到退让目标的线段仍满足原安全地图检查。

因此，保持会暂时覆盖普通Relay的额外几何余量报警，但不会忽略原地图线段失效或目标距离限制。60秒是新增覆盖规则的窗口，不是退让目标执行时长的上限；普通Relay随后仍可能保持同一目标。保持结束后，直接恢复普通Relay管理；若运动风险仍在，可按60秒尝试间隔再次退让。到达最终终点仍由原10米半径和完整安全记录判定；没有新增终点捷径或超时豁免。

**保持与生效时序必须一起理解。** 退让目标在 $t_s+1$ 生效。若没有提前退出，最早在 $t_s+H$ 提出替换、在 $t_s+H+1$ 生效，因此在未提前退出时，新增保护覆盖 $H=60$ 个控制步；保护结束后，普通Relay仍可继续保持同一目标。不能把决策前的“目标年龄59秒”误读成只给了59秒执行时间，因为当次旧目标动作仍会执行。

参数依据如下。它们是当前开发范围内的工作选择，没有被证明最优。

| 参数 | 本轮值 | 依据与限制 |
|---|---:|---|
| 正常额外留量上限 | 160 m | 继承R3；对照保留Relay120 |
| 历史窗口 | 10 s | 复用Relay的11点位置历史；不是风估计 |
| 外推、尝试间隔、保持窗口 | 60 s | 长目标已观察到的航向响应代理量90分位约55.4 s，取整为工作尺度；大量片段被截断，不能作为响应上界 |
| 外推余量门槛 | 80 m | 沿用原Relay几何报警的量级，作用位置改为实际运动外推 |
| 进度门槛 | 0 m/s | 只对不再朝当前目标取得净进度的情形介入；不把所有接近障碍都视为失败 |
| 退让距离 | 500 / 250 m | 500沿用现有前视尺度；250为半距离可行性后备，通道分支显示500可能不可行而250可行；未搜索最优距离 |

标定还观察到：长目标的完整120秒观察窗中，相对初始目标方向的横向位移90分位约135.6米。这个量包含正常帆船机动，不是严格直线跟踪误差，更不能据此重新定义安全半径。

## 4. 一个真实决策及其后续

场景 `s3271_037_channel_stable_1000`。下表来自确认回合 `confirmation/...__commit_away/r2_decisions.json` 和真实目标应用记录。

| 量 | 346秒时的实际值 |
|---|---:|
| 位置 $p_t$ | (342.066, −322.986) m |
| 当前目标 $q_t$ | (787.962, −443.562) m |
| 当前 / 10秒前余量 | 111.099 / 116.378 m |
| 10秒平均速度 | (−0.2921, −0.4984) m/s |
| 朝当前目标进度 $u_t$ | −0.1519 m/s |
| 60秒外推终点 | (324.540, −352.887) m |
| 外推线段余量 $\hat C_t$ | 79.969 m |
| 选中250米退让目标 | (545.848, −178.166) m |
| 实际生效时刻 | 347 s |

四个风险条件都满足。500米退让线段被原地图检查排除，250米目标可行且连通终点。随后并非立即脱险，方法还执行了后续退让。586秒选中的500米退让目标在587秒生效。

587秒，当前位置余量32.693米，退让目标线段余量16.498米；普通Relay门槛为 $\min(80,32.693-5)=27.693$ 米，因此普通规则又请求转回前进目标。主方法按条件保持继续退让。去掉保持后，新目标于588秒被替换。实际目标应用事件在588秒已经不同。日志在新目标应用前记录当步状态，因此两条已记录位置与动作轨迹直到588秒一致，589秒开始不同；604秒时位置分离首次达到5米。最终分别为安全到达937秒、最小余量4.784米，以及652秒侵入、最小余量−0.440米。

这说明**在该配对案例中，让退让指令获得执行时间改变了结局**。它不说明任意方向保持60秒都有效，也不说明4.784米余量足够稳健。这个较晚时刻的消融没有额外保存完整隐藏状态快照；不能混称为另22个逐项核对内部状态的分支实验。

**一个新实例反例。** `s5271_001_channel_stable_1000` 在102秒触发：目标年龄10秒、进度−2.192 m/s、当前位置余量136.347米、外推余量51.073米。原Relay后续管理在接下来60秒的实际最小余量仍有125.227米，其间还替换了6次目标，最终390秒安全到达。不能把这个结果仅归于控制器自行恢复。退让版改为863秒、多走1334.25米；去保持版与其完整轨迹完全一致。因此这次代价来自干预策略，不能归咎于额外60秒保持。退让目标实际从103秒持续到305秒，进一步说明60秒不是实际目标时长上限。正常路线更新和控制器转向会使匀速风险外推失准，满足触发条件不等于原管理即将失败。证据：`RUN/final/adverse_case001.json`（RUN路径见研究报告）。

## 5. 与代码一致的执行伪代码

```text
每次高层调用：
    ordinary = 原Relay.plan(当前可见输入)  # 同时更新因果位置历史
    若普通规划无路：沿用原异常/终止路径
    若当前退让目标满足保持条件：返回该目标
    若历史不足或尚未到下一次风险尝试：返回ordinary
    计算当前余量、10秒净速度、当前目标进度和60秒外推余量
    若运动风险条件不满足：返回ordinary
    记录本次尝试时刻
    依次检查500米、250米径向退让目标及终点连通性
    若没有合格目标，或目标与ordinary相同：返回ordinary
    记录退让目标和保持截止时刻；返回退让目标

导航runner：旧目标动作执行 → 物理推进1秒 → 必要时应用新目标
            → 用真实历史重编码；不重置或反事实改写历史
```

实现对应 `src/sailboat_routing/r4_planner.py::ExecutionPlanner.plan`；正常接力为 `r2_planner.py::RelayPlanner.plan`；时序和真实评价在 `navigation.py::run_episode`。主配置为 `configs/r4_methods.json` 的 `commit_away`。`target_grace=0`，普通新目标的全局年龄宽限是被淘汰的实验开关，不属于主方法。

运行配置、全部分母、对照和失败边界见 [R4研究报告](R4_RESEARCH_REPORT.md)。本方法目前只适用于本轮固定控制器和合成静态任务的实证范围。线性外推会受后续转向和未知风变化影响；最近单个障碍的退让方向可能被其他障碍限制；条件保持也可能产生绕行或延迟。最终判断必须看完整安全到达与成败交换，而不是报警次数、短期余量或单条成功轨迹。
