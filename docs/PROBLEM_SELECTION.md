# B问题选择：区域持续观测中的低速工作域

最终把候选1的应用任务与候选2的实际瓶颈联系起来：在有限区域观测时，先恢复低速迎风状态的操纵能力，再继续区域引导。没有继续A的guard调参，也没有另建训练平台。

|初始候选|实际核查与成本|决策|
|---|---|---|
|有限区域持续观测|Viel2018、Morge2022、Liu2025全文；传统阶段、中心、接力均实际运行。100m简单任务已有解；50m开发中心/接力同为100%，冻结新任务仍共同长期横漂。|保留应用任务，放弃“接力优于中心”的初始假设。|
|目标/风变化后的失速恢复|Bink2026全文已存在恢复能力研究。180s转向准入和后续低速分支显示，单独换舵不能解除部分低速帆力平衡，放帆可以。|成为选定任务的必要低层适配；不用训练也可检验成熟恢复行为。|
|按需详细预测调度|A有少量救回、误干预与CPU尾部证据，但没有证明调度有效；需额外时间协议且与A重叠。|本轮不选，不声称被否定。|

**真实缺口范围。** 是当前常规中心/接力反馈在一族低速迎风状态的长期横漂，不是所有成熟驻留方法失败。已有Liu NMPC和Bink RL未完整移植，不能声称超过它们。公平性由同任务的下风参考恢复、随视风放帆、最大放帆及对应阶段删除来检验；不能只拿到点RL或错误实现作基线。

**任务意义与尺度。** 1200s持续观测与到点结束不同，不要求帆船原地静止。50m为假想观测区域，测得90/180°转向需15–31s、位移31–44m，支持它是紧凑但可机动的尺度。位移不等于理论转弯半径，不据此证明任何旧论文空间定理。100m是唯一冻结推广维度。未来如有真实采样需求，应据该需求重新定尺度，而非宣称本轮50m是行业标准。

**为何此时不训练。** 已有动力学允许用成熟帆舵模式构造可证伪适配，并已出现闭环恢复证据。训练不是禁令；在没有证据表明简单模式不足前，不用新网络增加成本。没有加载旧14D/18D权重，也不把导入环境辅助模块写成RL运行。

**判别链。** 原始同前史分支→8场失败/普通配对开发→必要增速阶段删除→新的物理条件族冻结确认→一次100m尺度检查。第一版确认在用于开发后明确退出“未见测试”身份；所有失败及实现修正保留。第二版未按结果换种子或改阈值。

**首要指标和停止。** 完整1200s区内采样比例，保护最长离区、完整积分、最大半径/横倾、操纵量与CPU。强随视风放帆若同样有效，接受这一更弱接口/成熟方案的竞争，不强行宣称最大放帆独占价值。完成有区分力的确认与审查后停止无依据扩展，不为凑工作量耗尽24h。

**A/B关系。** 当前风可测的驻留与A无风输入的动态避碰是不同信息和任务，不能拼成同一系统提升。A保留独立交付；B先交真实方法、全部结果和边界，是否另行组织由人类作者决定。
