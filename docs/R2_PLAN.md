# R2 研究计划

目标：固定低层与安全判据，在未知风条件下保留R1安全能力、改善3/5km共同成功效率，并优先收敛到简单航迹点接力。

先比较：①原样R1 geom80；②只去掉150/300m径向候选，其他R1机制不变；③有同等地图留量、无候选评分的可见路线前视接力，合理比较接力距离/到点阈值。随后根据失败和效率证据，检验提前风险处理或路线保持，放弃无额外价值的复杂机制，不把一次径向实验当任务终点。

开发：R1 seed271的72场已见数据及必要的新开发实例；初筛先覆盖1/3/5km×四布局×三风况。复用旧R1原始对照，先做少量逐值复现验证。最终：主方法、强简单基线、原样R1及关键消融先冻结，再生成约72个独立新实例；新测试种子和具体协议在选型后、见结果前保存。不按测试结果调参或换主方法。

选型：先看安全到达和失败构成，再看同场共同成功航时/航程的均值、中位数与尾部，以及切换、换舷和成本；不以不显著证明等效。机制证据来自公平消融；复杂方案无独立收益则采用简单方案。

图：预先确定可复现的分层选例规则，覆盖正常、收益和退化；各距离独立实际航迹图、危险局部图、安全余量/进度/生效时序曲线、分距离安全与配对效率图。使用真实日志，PNG300dpi+SVG；离线HTML及轻量zip同步本地，最终直接展示3–5张PNG。

预算：12小时、8科学轮、4 CPU单数值线程工作进程、GPU0；至少预留约三分之一时间给冻结评估/图/报告。按关键节点做同家族provisional review，不以分数停止。保留旧结果、代码参照及未提交修改，不push。复用现有runner/分析，不新增平台。
