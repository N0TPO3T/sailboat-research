## 4. B：先找到值得解决的问题，再选择方法

### 4.1 不受旧题目绑架，但不凭空制造缺口

优先利用已有帆船和海洋机器人资产降低启动成本；这是成本偏好，不是领域永久限制。允许新的导航/控制/观测任务。完全跨平台的候选可以提出，但必须把新环境、数据、验证成本与现有替代路径并列评估；超出资源授权时集中询问。

不能把以下情形写成“现有工作效果不好”：
- 论文未测试某种条件，就断言其方法失败；
- 用本来只训练到点航行的策略当作唯一驻留基线；
- 故意不给传统方案必要观测，或不给比较模型同等合理标定；
- 仅制造极端不可行风况/初始碰撞/目标会穿岸的场景；
- 用新方法的胜负结果筛选测试分布；
- 依靠某个正常实现修复，泛称新算法优于整个方法类别。

研究可以从故障与坏例子出发，但要把具体机制抽象为有任务依据的条件族，提前定义确认范围，并保留容易情形与合理反例。修复成熟基线后问题消失，应承认该候选已经能被简单解决，改选任务或使用该方法，不维持弱基线。

### 4.2 首批候选：建议保留最多三个同时活跃的问题，而非三个庞大项目

先做短、集中的原始文献阅读和可运行基线试验。每个候选输出一张短卡：

> 应用背景 → 具体任务与可用信息 → 合理现有方法及其已知范围 → 本地复现/文献中可核实的缺口 → 成因假设 → 最小方法 → 首要指标和保护指标 → 预期为何有效 → 失败条件 → 资源成本。

不要只给研究方向名称、论文数量或网络组合。至少一项候选真正换任务，不只是再改 S15 的 guard。

以下仅为可选起点，并非已验证缺口或必须执行的方案：

**候选 I：受限区域的持续观测/驻留。**
从“到点即结束”转为在预定义区域内保持尽可能连续的观测。比较成熟的驻留/导航模式切换方法，而非只比较不断追中心点。指标可为区域内时间比例、连续离区时长、重新进入时间和操纵成本。区域尺度、风况与任务时长必须事前有物理依据；不要求帆船原地静止。不要一开始捆绑海流、波浪、动态障碍和完整传感。

**候选 II：目标或风况改变后的失速/换舷恢复。**
关注航行中目标切换或合理风变化后，船进入低速、无法持续推进的状态。既可采用成熟机动模式管理，也可在已有权重上进行连续任务/恢复课程训练。必须先确认问题在合理现有控制器上可重复，不将原论文已验证的普通风况故意写成新缺口。比较预算相当的常规续训、域随机化或适合该任务的简单控制。必要换舷导致的短时负进度不直接等于失败。

**候选 III：需要时才使用高成本预测的决策。**
基于 A 已有“多数任务简单方案足够、少数任务详细预测有用、误干预有大代价”的观察，研究是否能用因果的残差、分歧或风险信息调度模型/干预。详细预测器不当作绝对正确的老师，不用真实未来判断何时开关。需要与经过合理标定的 L、R、固定调用/固定周期和必要 guard 对照比较。若目标是计算受限导航，计算等待必须真实进入运动时序；只展示函数快不够。

可以用检索发现的更好问题替换上述候选，不因它与已有方法相似而淘汰。B 不必是动态避碰，也不必无直接风观测；若改变信息设定，明确传感假设并给适用对照相同信息。已有安全半径和成功条件不是所有新任务不可改变的常数，但新定义必须有独立任务依据、对各方法一致且在确认前冻结，不能根据成绩改判分。

### 4.4 连续执行：问题筛选不等于只交选题报告

在已授权预算内完成“基线诊断 → 方法原型 → 配对开发 → 必要消融 → 有希望后新实例确认”。不要求每天凑满一轮，也不要第一个假设失败就停止全部 B 工作。

首批用少量可解释的工况识别有行动空间的缺口，选出一条最有希望的路线集中投入。问题若已被合理基线解决、不可行性无法解除、或成本超出本轮，就记录原因并换路。允许开发期改奖励、训练、输入、控制器、预测与接口；成熟方案直接有效即可。

训练分支先测环境交互/更新吞吐和样本需求，不把明显不充分的短训练当成反证。若主张训练策略稳定改善，应安排独立训练重复；不能用同一个checkpoint的大量评测代替。

## 5. B 的成功标准：效果而不是评语

每个选定问题事前指定一个首要任务指标，并指定安全/完成率/计算/能量等不应严重退化的指标。不要用临时加权总分掩盖明显损失。

“明显”是任务上值得关心、跨多个独立实例方向稳定、能由机制解释的改进，不等于必须100%成功，也不等于为了p<0.05反复追加样本。改善可以集中于事先定义且有意义的背景，但不能只在事后挑选的一个极端例子成立。

若主打效率，应说明同样任务和安全要求下的航时/资源取舍；同时报告所有任务的成功失败，不能靠排除失败获得速度优势。若主打恢复，应报告恢复率、恢复时间和正常航行受干扰代价。若主打驻留，应报告全任务期间区域内/外表现，不能事后删去长期离区段。

先检验 B 自身是否成立，再做一项与其假设直接相关、成本合理的推广检查，如新的任务尺度、方向、扰动幅度或另一个模型参数范围；不一次承担所有泛化维度。没有验证的外推只列为后续可能，不写成已实现能力。

不得据模型分歧直接声称置信概率，不得据经验最大误差声称统一安全界。离线真值可用于诊断和明确标注的训练；正式在线策略只能读取声明的信息。
