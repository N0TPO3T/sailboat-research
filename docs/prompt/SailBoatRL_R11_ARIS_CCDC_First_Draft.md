## 4. 本文中心与写作主张

### 4.1 已选定的中心

研究问题：位置参考不能直接等同于帆船将执行的航迹。对于继承的学习型帆舵控制器，能否通过预测不同候选参考及其保持／恢复协议诱导的闭环运动，改善限定动态会遇中的参考选择？

方法：借鉴 Generalized Velocity Obstacles（GVO）的控制诱导运动思想，把候选控制适配为位置参考执行方案。利用独立动力学、局部因果风估计和同一个局部策略预测候选运动，进行同步安全余量与实际代码规定的代价评价，再滚动执行所选参考。

实验范围：**理想计算条件下的闭环仿真**。规划计算不推进物理仿真时钟，但本船仍经过实际动力学与局部反馈执行。理想计算不等于真风／未来轨迹可见、不等于理想航向跟踪，也不等于参考没有既定的控制步生效顺序。

可采用类似以下题目作为工作稿起点，作者可在不改变范围的前提下优化：

> Candidate-Reference Execution Prediction for Sailboat Collision Avoidance: A Closed-Loop Simulation Study

不要求机械采用题目，不以方法英文缩写或新命名制造创新。

### 4.2 可保留的贡献和必须说明的边界

可以清楚主张：文献思想在位置参考与循环帆舵控制器接口上的具体适配；候选执行协议的可复现定义；闭环比较与同状态证据揭示参考选择的条件性作用及干预代价。

不能主张：新 GVO 理论、新 SAC／注意力网络、普遍优于反应式导航、15 秒配置必要或最优、实体碰撞率显著下降、实时部署、形式安全保证、完整 COLREGs 合规。

静态输入适配与 Relay 是系统基础。R10 的匹配障碍集合对照削弱了“边界数值公式独立导致收益”的主张，不把 R6 的 54/54 当作本文中心公式的新证据。

最重要的篇内局限是：**搜索比指定保持规则更合适，不代表触发避让本身总有必要；有些反应式本来安全的航行被干预后产生额外代价。** 不能只谈实时部署等范围外问题，而回避这一点。

论文表达应集中、直接：正向机制讲清楚，限定与负面结果在相应结果和讨论中说明，不用每段重复“不是、不能、不支持”。不写成自我否定清单，也不通过删去反例变成宣传稿。成熟方法可以直接采用并准确引用，不必为 CCDC 强行增加定理、网络或模块。
