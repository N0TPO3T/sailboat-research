# 阅读与使用

先打开 **实验全说明.html**：含目录、完整22节说明、5张结果原图和逐场景附录，可离线阅读。图已内嵌，单独移动HTML仍可阅读正文、图和附录；证据文件链接需要保留整个文件夹。

需要复制、批注或自行重写时，使用 **实验全说明.md**。详细数值使用 RESULTS_24.csv、SCENES_24.csv、PAIRED_TIMES.csv。不要从截图抄数。

`python rebuild_evidence.py` 在本目录用Python标准库复算主结果，不运行导航。可选`--archive 路径`核对原完整恢复包的trace汇总与冻结源码；不传时新的复算记录会明确标为未执行原包核对。本次带原包核对的收据另存为 AUTHORING_VERIFICATION.json，不因普通复算覆盖。

本资料包是**实验说明与轻量证据包**：包含文字、图、CSV、JSON、复算脚本，不含完整模拟器、策略权重或完整恢复包。它允许复算已有表格，不等于能够直接重跑全部航行。完整恢复条件、历史入口限制和资产身份见正文第21节。

本文未改动论文、科学实现、配置或原始实验。没有新训练、新导航实验、模型标定、服务器同步、push或投稿。本文提出的假设整理和后续验证建议不冒充已经执行的实验设计或结果。

旧归档README原文保留作证据，其中许可状态属于历史文字；当前研究使用和提供审稿材料的许可已经确认，但原始训练运行对应关系和公开发布状态仍有未确认项。不要把旧README中的所有状态当作当前状态。
