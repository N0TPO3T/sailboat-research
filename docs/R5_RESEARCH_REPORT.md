# R5研究报告：帆船恢复监督的文献接入与位置目标适配

**结论：得到一个有来源、可运行、在预定义风险工况有初步收益的位置目标恢复候选；尚不足以替换默认Relay160，更没有证明优于Relay120的普遍长程效率。** 本轮采用Jambak等（2026）的恢复监督结构，主候选为90m恢复尺度、60s位置目标检查周期及90m退出阈值；科学实现和配置在新实例生成前冻结。

新36场风险任务中，主候选36场安全完成，Relay160为33、Relay120为32；相对160的3场新增完成原本都是超时，不是三次碰撞。新36场常规任务中，主候选与Relay160均34场安全，Relay120为35场。常规共同安全34场里，主候选比Relay120平均慢99.06s、中位慢15.5s；相对Relay160平均快30.38s，但中位为0、探索性区间跨0。风险共同安全33场相对Relay160平均快103.79s，中位仍为0。不能把不同任务族混成单一总体收益。

因此建议将它作为**文献适配与条件性应用验证的候选方案保留**，保留Relay120/160和简单固定位置对照，不新增模块包装结果，也不立即更换项目默认参考。风险完成差异只有3个不一致对（精确双侧p=0.25）；当前样本不支持普遍安全提升或等价结论。选题可以围绕可重复的接口适配与收益—代价收敛，但“全面更安全、更高效”这一主张不成立，未达到可直接投稿的确认状态。

## 问题、来源与本轮可检验命题

R3/R4已经说明：路线留量有实际价值；几何可行航段不是固定SAC-LSTM的实际航迹；更早的目标改动可能救回危险过程，也可能打断原本成功的接力。R5不重新提出一个预测器，而是接入 Jambak、Bayezit、Reyhanoglu（2026，Drones，DOI:10.3390/drones10080578）的恢复方向、方向评分和恢复状态结构。完整公式、作者公开材料及未指定参数已核对；见中文方法说明中的来源映射表和本轮 `literature/R5_WFRS_SOURCE_READOUT.md`。

最小接入版保留原文12m几何留量、12/18m进入/退出尺度，但仍须增加本项目的位置目标、500m目标距离和管理器时序；原文风投影、PD舵控与帆角规则不适用本任务，没有接入。因此它称“原文尺度的最小接口适配版”，不能称完整WF-RS，也不能用其失败否定原论文。补充阅读的反馈运动预测论文针对指定单轮车反馈控制器，其解析包络未实现、未冒充SAC-LSTM误差界。

本轮检验：成熟的几何恢复结构能否在这个位置目标接口下改善完整任务；如果直接接入不足，空间尺度和更新/退出时序能否使其有可区分作用。开发阶段的改动只涉及同一简单监督器的配置。没有新网络、低层训练、真实风输入或在线环境副本。侧奖励和最短恢复结构始终保留，故本轮没有隔离证明每个继承模块独立必要。

## 公平性与实例划分

初始代码版本为 `ed6ec5850a8e468d1f7033b4ed5008cd87163a4b`。五个开发批次使用相同的18个源文件散列；批次记录的Git HEAD加未提交源码快照共同定义实际实现，不能误说初始提交已经包含R5。最终科学实现冻结为 `822817495ac9ddae06a2743a021b8aa0d160f2d7`。分析与作图后来有独立修改，冻结后规划器、实际配置、生成器和公共执行代码不变。

所有方法采用固定14D SAC-LSTM@7200、匹配归一化器、同一地图/种子/风函数、动作限幅、坐标系与真实历史重编码。目标仍在t提出、t+1进入Actor；初始目标另算。评分始终使用实体外60m安全圈、10m终点半径、1/3/5km对应1800/5400/9000s时限以及一秒实际位置段。侵入后终止为NoRouteError仍记缓冲侵入，原终止原因另存；不把它计成普通基础设施失败。计算开销来自共享CPU，属于描述性测量。

开发由原21场扩至56场，其中44个已见常规场景、12个预定义开发风险场景。扩展同时补齐强简单候选与最小适配器，避免用21场对56场选方法。70条旧Relay结果复用之前的完整记录，身份检查覆盖物理场景、套件与配置；另外18个旧基线在本轮逐值复现。复用的耗时不作为新测微基准。

最终参数及6种方法先冻结，再生成72个新实例，共432回合。常规36场为seed6271、四布局×三种风型×1/3/5km；风险36场为seed7371、初始余量80/160/280m×方位−45/0/135度×稳定/快变风×两次重复，含预先定义的抖动。135度是后方障碍对照。风险分层没有按任何方法失败筛选；其人为比例不能估计自然任务失败频率。旧seed271/371/1271/2271/3271/4271/5271及开发风险均不再称未见测试。

样本单位是完整场景，而非连续帧或分支。主要报告安全完成与配对得失；航时/航程只在各对照明确的共同安全集合内比较，失败提前停下不算提速。探索性场景bootstrap区间与精确不一致对检验只辅助描述，小样本和少量差异不能推出等价或普遍增益。所有任务与失败保留，未在冻结结果后调参。

## 风险工况中的真实变化及解释边界

预设选例规则取首个相对Relay160新增安全完成的风险场景：`risk7371_000_c80_b-45_stable_1000`。初始径向余量78.149m，进入90m恢复条件。Relay120/160均提出(100,75)m的125m近目标；在1s又提出(75,75)m、2s生效。最小12m适配版没有此时进入恢复。这三者最终1800s超时，Relay实际最小安全余量43.911m，未侵入；不能称其发生碰撞。

主候选的两个方向都通过几何/路线检查，对齐分数为−0.976023和+0.976023，承诺奖励均为0。它在第一步前选择(325.108,379.875)m、距离500m的位置目标；此时在额外规划圆内，方向是截断公式给出的径向垂线，不是该圆的真实切线。60s时位置(68.774,152.460)m，径向余量171.957m，退出并提出(300,175)m目标，61s进入Actor。主候选509s安全到达，最小真实余量78.149m，实际航程1468.388m、航中改点3次。Relay1800s只航行1338.215m且距终点仍远；其较短航程来自未完成任务，不能记作效率优势。

退出135m版和固定位置90m版在该例同样509s安全，完整轨迹相同。因此这个图支持“90m恢复接口改变初始任务过程并接回终点”，不证明90m退出、60s重发或每个继承模块独立必要。位置方向、长度和管理时序同时区别于Relay；本轮没有额外的等长度非切线对照，不能把全部收益只归因于切线方向。

另一个预设风险实例`risk7371_026_c160_b0_stable_1000`在航行中159s进入恢复，160s应用(3.740,453.581)m，219s退出、220s接回；主候选641s安全，Relay160/120均1800s超时。它补充说明收益不全是初始目标替换，但仍属于完整策略配对，不是保持所有后续目标不变的单决策因果实验。以上逐值证据在同名`*_evidence.json`与原始日志中保留。

## 常规代价与未解决的失败

常规`s6271_000_islands_stable_1000`是相对Relay160共同安全集合中最大的时间代价：Relay160532s、Relay120564s、主候选943s，主候选相对160增加411s；航程从1554.543m增至2869.941m。主候选在244/427/756s三次进入恢复，形成8个恢复目标提案；例如244s给出(783.227,434.671)m，304s更新为(16.841,571.580)m。实际航迹出现更长绕行。固定位置90m版539s安全，说明复杂一点的周期更新并不必然优于简单保持。最小安全余量也从Relay16048.853m降至主候选35.428m，不能称“多走一点换更安全”。这是完整策略的实测误干预代价；没有进一步隔离哪次改点或哪项配置单独导致全部损失。

常规`s6271_033_channel_fast_5000`是相对Relay160共同安全集合中的最大航时收益：6688→5319s，减少1369s；但Relay120只需3269s，仍比主候选快2050s。主候选在3343s、4470s进入恢复，两个阶段后接回路线；该案例不足以支持优于合理简单Relay120的长程提效主张。图同时展示这三个方法，避免只选较慢的160作比较。

## 结论边界

1. 几何可行与任务成功仍不同。候选航段、候选点连通性、经验90m/160m留量都不是实际执行包络或安全定理。
2. 正式方法没有原论文的直接风可航性分支；方向对齐评分不能保证帆船能够沿该方向运动。删除该分支后的结果只属于本接口适配。
3. 进入恢复常发生在额外规划圆内，公式截断得到径向垂直方向，不能把这些候选统称为真实切线。
4. 高层周期同时作用于目标重发与恢复退出检查；绕行侧保持不等于位置保持。没有分别证明侧奖励、承诺时间与目标距离的独立因果作用。
5. 活动障碍索引在一次恢复中固定，其他障碍只参与筛选和阻止退出。没有验证多障碍交接策略的可靠性；无候选回退Relay不是刹停或兜底保证。
6. 新实例来自有限合成生成族，不代表实海况、动态船舶、连续积分安全、其他学习型低层或额外噪声。风险完成增益与常规效率代价必须同时保留。

本轮以应用方法的可运行性、可区分证据与边界交付，不以相似于已有工作为淘汰理由，也不以完成实验或AI评语宣称达到CCDC录用条件。R3英文初稿保持原样，只另存方法和相关工作更新建议。
