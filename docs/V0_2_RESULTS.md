# V0.2 固定25m跟踪裕量：开发实验报告

## 结论与停止原因

**本轮完整假设未获支持。** 同状态复算中，25m能过滤已知危险候选B；但从初态启用后，三种方法都在165秒因候选集清空而失败，没有完成安全到达。原本成功的几何/估计风方法退化。未侵入安全域不等于任务成功，更不构成安全保证或导航收益。

按结果前固定的 [V0_2_PLAN.md](V0_2_PLAN.md)，6回合主实验后停止，**18回合回归未启动**。没有调整裕量、风权重或切换阈值，没有训练。25m是由已见开发失败设定的参数，不是独立测试结论。

## 同状态机制核对与真实首次分歧

原t=70共同状态上，在独立管理器副本调用原评分：B余量23.004m、A余量115.268m。0m复现原决定：几何/估计保留A，oracle选B；25m在三模式均过滤B、保留A和C，最终都保留A（hysteresis）。这仅证明本状态筛选作用，不等同整回合效果。

闭环从初态启用裕量，**t=0初始目标即不同**：0m为(483.809,−126.211)，航段余量1.211m；25m过滤它并选择(437.543,−241.984)，余量116.984m。首个不同动作在记录time=1行。因此25m回合t=70已非旧状态，不能用“只在t=70挡住B”解释整个新航迹。

## 无候选与保持机制

25m三模式航迹相同，改点在t=30选/t=31用及t=158选/t=159用。t=164旧目标(941.267,−150.564)航段余量25.387m，按原重规划周期继续持有。t=165自身位置仍在安全域外，但原几何可行的三个候选航段余量分别为 **21.743、9.970、21.446m**，全部不足25m；现有 `NoLocalTargetError` 终止了回合。没有放宽到0m、改变全局地图或生成新候选。

过滤日志记录：每种25m运行selected=3（含初始）、replan_period=148、minimum_hold=5、hysteresis=10、NoLocalTargetError=1。决策时旧目标不满足25m仍被下发保持的次数为0；不能据此宣称步间轨迹始终满足25m。原保持分支没有重写，旧目标被过滤时按原“无incumbent”路径处理；本例最终无任何合格候选。有限集合清空不证明全局不存在可航路线。
