# R4 研究报告：退让目标及其执行时间

> 科学实现冻结于3c5e44f；一次72新实例×5方法评估已完成。旧开发与新实例结论分开报告。

## 结论与本轮定位

本轮形成了一个具体、可运行的候选机制：**根据因果运动历史定义经验风险触发条件，选择几何可行的退让目标，并有条件地保持该目标，让固定低层有时间响应。** 这是对Relay160的局部高层适配，不是低层重训、显式风估计或安全证明。

最有区分力的发现不是报警次数增加，而是两件事：较早的目标替换确实能改变部分完整任务结局；新退让目标也可能被普通路线规则在下一秒撤销。后者有直接配对消融证据。普通目标的统一60秒年龄宽限则出现正反效果，并与一个控制周期的生效时序相互作用，因此没有纳入最终方法。

## 2. 真实机动观察：用于定尺度，不当作安全界

复用R3的72个seed2271场景×Relay120/160，共144个完整旧回合。按实际目标应用切分得到2064个目标片段；每段最多观察120秒，遇下一次改点或任务结束就截断。失败回合和截断片段均保留。

航向响应代理量定义为：初始航向相对该段初始目标方位误差至少20度时，首次连续3个样本将绝对误差降到 `max(10度, 初始误差/2)` 所需时间。它不是到达目标时间，也不是航迹严格跟踪指标。统计为：582段观察到响应，1160段初始误差较小无需该代理量，295段被下一目标截断，25段完整观察窗内未观察到响应，2段在任务结束前未响应。

目标距离超过350米的988段中，359段观察到响应，其响应时间中位数18秒、90分位55.4秒。该组完整120秒观察窗的408段，相对初始目标方向的横向位移90分位135.55米、最大180.97米。小于等于150米的779段只有8段具备完整120秒窗口，不能用这些少数幸存窗口推断短目标的因果优劣。

这支持“需要给机动留出时间和空间”的工作判断，但不证明60秒最优，也不能从约136米横向位移反推一个安全留量。最终仍继承R3的160米留量上限，只把60秒作为需要闭环检验的响应尺度。原表：`RUN/response_segments.csv`、`planning_space.csv`、`response_summary.json`；补充图：`RUN/figures/response_calibration.png`。

## 3. 同状态闭环分支：替代目标有时有效，有时无效

先从初始状态完整重执行4个不干预回合，核对与R3原记录的全部物理/动作/风/目标轨迹、目标事件及结局一致。没有仅复制位置和速度，也没有清空记忆。随后执行22个分支：两个失败案例的多个较早时刻，以及一个正常成功、一个开阔水域对照。

每个分支在旧目标动作已经算出、规划之前记录状态。与不干预回合对应时刻逐项核对了记录中的物理内部量与连续性/RNG摘要、Actor隐藏状态和前序输入/动作、真实历史/命令摘要、局部坐标系、原目标、Relay管理状态以及待执行旧动作。22个分支记录状态全部相同；直到新目标生效边界的旧动作轨迹前缀全部相同。19个分支实际改点，2个因几何不可行不改点，1个返回原目标。实际改点均保持 `t选点→t+1应用`。

分支共享同一外生风场函数，各自按实际位置和时刻采样。对16440条分支样本离线重算风方向，与日志完全一致；没有沿用原航迹的风序列。检查结果分别在 `replay_equivalence.json`、`branch_validation.json`、`branch_field_validation.json`。

## 4. 最终保留的机制与淘汰项

首先实现了因果运动触发：近10秒净接近障碍、朝当前目标进度非正、当前余量小于160米、60秒匀速外推线段余量小于80米。替代目标按最近障碍反方向尝试500米，再尝试250米；必须通过原安全几何与终点连通检查。没有扫描更多距离或训练预测模型。

最终保留一个与目标选择直接相关的状态：**退让指令的条件保持**。新退让目标生效后，在60秒响应窗口内阻止普通附加余量阈值把它立即撤销；原安全线段失效、超过550米或进入100米接力距离时不再强制保持。普通规划本身的无路异常仍按原流程处理。窗口与原一秒生效延迟一并计算，未提前执行新动作。

关键案例为 `s3271_037_channel_stable_1000`。586秒选择的退让目标于587秒生效；当时实际余量32.693米、该目标线段余量16.498米，普通Relay阈值27.693米。因此没有保持时，普通规则又在587秒选回前进目标、588秒应用。实际目标应用在588秒已经不同；日志在应用前记录当步状态，所以已记录位置与动作轨迹直到588秒一致，589秒开始不同，604秒位置分离首次达到5米。保持版937秒安全到达、最小余量4.784米；去保持版652秒侵入、最小余量−0.440米。

这项较晚时刻的比较属于**完整回合配对消融**，没有额外保存该时刻的Actor/RNG快照，不与上一节22个完整记录状态的分支混称。证据：`commitment_case_evidence.json`、确认回合的原始轨迹及 `base_decisions.json`。关键图：`figures/commitment_case.png`。

两项未保留的设计也有实际反证：

1. **取消进度条件、只靠预测余量报警：** 开发38场中37场安全到达，实际介入16场、44次；原带进度条件版本介入8场、14次并38场安全到达。若干正常场景多用数百秒。该历史版本还出现7个超过550米仍被保持的时间步，全部在未保留的ungated案例025；范围检查已修正，不能把这个实现差异混作最终算法收益。
2. **给所有新目标统一60秒年龄宽限：** 案例005避免了一次8秒龄目标上的过早干预，节省245秒；案例013却屏蔽了有效干预，多用218秒。037的表观成败改善还包含第二次提案从406延到407秒的相位变化。不能据此声称统一宽限验证了普遍的响应机制。补充图 `normal_response_case.png` 同时展示两种方向；该开关在最终配置中为0。

普通几何更新可能打断退让这一问题，是保留条件保持的具体依据。不能从中推出“越少改点越好”。最小余量只有4.784米的成功也提醒我们：完成任务不等于具有可靠安全裕度。

五种方法全部重新运行，同一场景共享地图、风函数、种子、低层、时限和真实安全定义。完整安全到达为主指标。实体碰撞、缓冲侵入、超时、区域退出和其他无路失败分开记录；失败不从分母删除。表中结局按实体碰撞、缓冲侵入、时限/区域退出、其他终止的优先级互斥分类；原始退出reason同时保留，分类不等于因果归因。时间/路径仅在明确列出的共同安全成功场景比较，成败交换另列。没有根据冻结结果选择新参数或新增测试seed。

## 7. 仍然存在的边界

- 60秒线性外推不模拟转向和未知风变化。正进度也不保证安全，负进度也不必然是失败。触发规则会漏报和误报。
- 只考虑最近障碍的径向退让，可能被其他障碍或地图边界限制；500/250米都不可行时没有新的恢复动作。普通规划无路仍会终止。
- 条件保持暂时覆盖普通额外余量报警，可能保留一个动力学上仍有风险的目标。原线段可行不等于实航可行；新实例中出现的损失必须如实保留。
- 固定窗口、两个退让距离和80米门槛是有限开发范围内的经验选择，未证明最优。标定的删失和场景选择限制不能被公式形式掩盖。
- 开发集中的4.784米安全成功接近边界；整体成功率和局部成功图不能作为安全保证。没有外推到连续积分安全、噪声新增设定、动态避碰或其他低层控制器。
- 本轮没有证明方法新颖性或完整投稿充分性。R3英文稿保持不变，研究报告承担方法和证据说明职责。
