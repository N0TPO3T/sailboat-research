# A方案公平对照实验包

本轮任务：暂停投稿，先检验协议匹配的低阶校准，再做新任务配对验证；依据预先冻结的停止规则决定是否继续详细预测路线。

## 阅读顺序

1. `EXPERIMENT_PLAN.md`：在结果前冻结的实验目的、划分、评分、任务清单规则与停止条件。
2. `RESULTS_ZH.md`：完成后的中文结果说明；存在此文件不替代完成收据。
3. `completion.json`、`AUDIT.json`：正式执行退出与原始轨迹指标复算。缺少其中任何一个时，不应称全流程完成。
4. `RESULTS.json`、`episodes.csv`：全部配对结果、失败、航时和计算代价。
5. `calibration.json`、`CALIBRATION_BREAKDOWN.json`、`grid/`：所选参数、完整48点训练结果及逐协议误差，包括不利结果。

术语：`reactive` 为原反应式导航；`simple` 为原低阶预测；`simple_star` 为本轮协议匹配校准后的同结构低阶预测（L*）；`sampled` 为保持原设置的详细闭环预测（S15）。名字只是日志标识，不代表贡献。

## 资产和记录

- `frozen/`：本轮实际使用的原科学源码、依赖锁定文件和继承资产副本；未改动原模型或算法。
- `SOURCE_HASHES.json`、`RECOVERY_IDENTITY_CHECK.json`：源码/资产哈希和与原完整恢复包的核对结果。42项共同科学资产逐字节一致；恢复包未包含的额外旧14维资产单独列出，并未替换18维实验控制器。
- `inputs/`、`INPUT_HASHES.json`：校准所用12条旧开发轨迹、旧24任务三方法的汇总记录，以及见证所需的一条旧真实轨迹。这里没有伪装成完整旧72条原始轨迹恢复包。
- `branches/`：全部72条60秒固定协议真实分支，含历史前缀和选中协议前15秒一致性检查。
- `old_Lstar/`：原24任务的新低阶对照原始轨迹；原方法结果从旧记录复用。
- `new_paired/`：8个几何、各2个风场实现、三种方法的48条新航行原始轨迹。
- `new_scenes.json`、`FREEZE.json`：先于校准结果冻结的新场景及内容哈希。
- `run.log`、各阶段`*_progress.json`与`*_complete.json`：完整运行过程与阶段收据。`smoke/` 是12步准入见证，不计入科学任务样本。

数据是私有继承资产研究使用材料，不因本次本机备份获得公开发布许可。未向公共存储上传。

## 读取与复核

JSON/CSV 可直接读取。`audit_results.py` 使用 `frozen/src`，仅从保存的轨迹重算本轮72个完整回合的航时、路径长度、安全裕度及安全完成，不启动仿真：

```text
python audit_results.py /绝对路径/解压目录
```

软件依赖见 `frozen/requirements.lock`。原验证环境为 Python 3.13.11、CPU Torch 2.13.0、NumPy 2.4.6、SciPy 1.18.1；不能把其他环境的import成功当作轨迹复现证明。

如确需重新运行，可使用 `prepare_reproduction.py --output /新目录` 创建新的独立副本。该工具只重新定位路径、准备副本，不启动实验，也不覆盖旧结果。按其输出先执行 `a_fair.py smoke`；见证成功后再另行决定是否运行完整重复。重复相同种子不构成新的独立科学样本。

原冻结编排器在全部航行完成后的汇总阶段遇到一个已记录问题：旧 JSON 用 null 表示无静态障碍时的无穷大裕度。保留的原 a_fair.py 没有改写；`finish_analysis.py` 仅在核实该场景确实没有静态障碍后，将该字段解释为正无穷并完成汇总和复算。完整重复后执行 `python finish_analysis.py` 完成这一分析步骤；它不运行航行工作进程。原错误见 failure.json，修复及退出状态见 ANALYSIS_RECOVERY.json 和 completion.json，不能把原编排器说成无错误退出。

服务器绝对路径留在历史收据中用于追溯；准备复现副本后，读取输入使用包内 `inputs/`，不依赖作者服务器上的相对目录。

## 结论边界

旧24任务已被研究者观察，新增L*结果只是增强对照。新测试只有8个独立几何；同一几何的两个风场是组内重复，压力任务过采样不代表真实总体。计算期间物理时间仍暂停，不支持实时部署。安全指规定圆形缓冲区代理；失败、同航时、实体碰撞需要分别解释。运营停止门槛不是统计显著性检验，也不是所有复杂模型无价值的证明。
