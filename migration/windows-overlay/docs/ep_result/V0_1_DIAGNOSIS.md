## 1. 第一次分歧：t=70 的同状态评分

三方法此前一致。t=70 位置 `(120.2026,-33.1661)` m、航向 −0.758994 rad，旧目标 A；上一改点 t=33、上一重规划 t=60，故30秒保持期和10秒周期均已满足。oracle t=70 选 B，t=71 下发；首个不同动作在原 trajectory 的 **time=72** 行（对应71→72秒控制步），并非到t=90才分歧。

按 [planner.py](../src/sailboat_routing/planner.py) 287–311行，分项沿用代码：`remaining_map_distance`=当前位置至候选距离+候选至终点的几何路径长（权重1）；`local_wind_penalty`=0.3×min(候选距离,500)×max(0,cos(候选方位−吹向风角−π))²；`turn_penalty`=20×航向圆周角差绝对值；`change_penalty`=0.1×候选至旧目标距离。总分越小越好。下表分项均已乘实际权重；三元组顺序为**几何 / 真风 / 估计风**。

| 候选坐标(m) | 地图项×1 | 转向项×20 | 改点项×0.1 | 风项×0.3（三种） | 总分（三种） | 筛选 |
|---|---:|---:|---:|---|---|---|
| A (418.611,−235.021)，旧目标 | 987.363 | 3.285 | 0 | 0 / 33.929 / 1.664 | 990.648 / 1024.577 / 992.312 | 通过 |
| B (596.126,−186.452) | 944.835 | 8.948 | 18.404 | 0 / 14.098 / 0 | 972.187 / 986.285 / 972.187 | 通过 |
| C (559.212,−272.479) | 1018.208 | 5.198 | 14.550 | 0 / 34.362 / 0.124 | 1037.956 / 1072.319 / 1038.080 | 通过 |
| D (616.358,−95.052) | — | — | — | — | — | 直线安全余量−45.081m，评分前剔除 |

**三个输入的评分首选都是 B，完整排序都是 B<A<C，没有任何候选对翻转。** 真风仅改变风项：A比B多罚19.831分，使A−B由 **18.461** 增至 **38.292**，超过25分改点阈值。估计风有效、世界系吹向63.051°，真风90°；其A−B只增至 **20.125**。因此建议目标均B，最终下发分别 **A / B / A**；几何与估计风的未切换原因均为 `hysteresis`，oracle 为 `selected`。不是无有效估计或真风未接入。

## 2. 从切换到侵入：检查的直线与执行的轨迹不同

障碍中心(500,0)，实体半径55m、缓冲70m，排除半径125m。用原 `segment_circle_clearance`：t=70 旧目标A航段余量 **115.268m**，新B航段 **23.004m**；t=71真正下发时B航段仍 **23.465m**。一秒延迟没有立即让航段失效。oracle 此后没有再改点。

随着实际航行，当前位置至B的直线余量在t=140/148仍为 **10.282/1.023m**；但148→149秒实际轨迹线段首次为 **−0.096094m**（原控制步线段近似，不是精确积分曲线），首个侵入记录位置 `(454.9842,-116.5099)`，实体余量仍69.903906m。此位置偏离t=70计划直线约 **23.304m**，方向朝向障碍一侧。几何/估计风整回合最小安全余量为76.590m。

t=149起点已在缓冲区内；原 `StaticMap.route` 对该记录重算得到 `NoRouteError: Start or final goal violates map constraints`，对应 planner.py 255–256行调用以及82–83行起终点检查；navigation.py在物理步之前捕获，未再执行149→150秒。**NoRouteError是侵入后的几何前置条件失败，不是先无路才撞入缓冲区。** 本例支持“目标直线可行不保证真实跟踪安全”；未发现判交放行一条穿缓冲区直线的证据。切换后的低层反应、风变化及记忆重编码各贡献多少，尚未确认，不能只由时序归因。

## 3. 为什么估计风在12场都没改变执行

逐值配对同一非风输入、相同候选，校验估计总分减风项等于几何总分（误差<1e−9）。分母是旧日志保留的 **198条配对决策**（每30秒、每次改点及首条），并非随机抽样或全部控制步。以下按顺序归类、互不重叠：

| 分类 | 条数 |
|---|---:|
| 估计无效/几何回退（均各场t=0） | 12 |
| 有效，但筛选后仅一个候选 | 3 |
| 有效且有替代候选，但全部风罚为0 | 19 |
| 风罚非零，完整排名未变 | 70 |
| 完整排名改变，但首选未变 | 76 |
| 首选改变为旧目标；几何的替代首选本就未过阈值 | 16 |
| 首选改变为另一目标，但估计改善未过阈值 | 2 |

18条首选变化的两种方法日志均记 `hysteresis`，不能把其中16条也解释成“估计想换点被挡住”。本样本未见保持时间/重规划周期造成首选分歧消失。相对几何方法“目标改变但动作仍相同”为0：全12场完整目标切换序列、动作/轨迹一致（不含计算耗时）。**其余4824个已推进控制步缺估计风/候选日志，不能归因分类**；3次终止规划异常也不在5022个已推进步的分母内。已记录198条无缺字段，不能据其比例外推全量频率。

数值例子：fast_wide_channel t=30，旧目标(500,0)几何分 **1010.138**，侧候选(499.132,93.606)为 **1026.939**；加估计风后分别 **1118.792/1109.067**，风项确实翻转首选，但收益只有 **9.725<25**，故仍保留旧目标。风罚分别108.654/82.127，不能概括成“风权重太小”。主要已观测机制是评分首选不变，或首选差异没有转化为通过门槛的改点。

## 未确认、唯一建议及复现
