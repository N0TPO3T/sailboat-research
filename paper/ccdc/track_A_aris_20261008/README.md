# CCDC 2027 revised manuscript

Start with manuscript.pdf and AUTHOR_NOTES_ZH.md. This is a local editorial edition of the user-specified Track A draft; it does not supersede or synchronize the server research workspace. The original draft remains unchanged in ../track_A_submit. Edit manuscript.md and rebuild with build_docx.py, then export_pdf.ps1. Native Word equations remain editable. LaTeX_source.zip contains synchronized optional source, whose native compilation has not been verified.

The two independent, fresh-context ARIS reviews and applied fixes are preserved in PAPER_IMPROVEMENT_LOG.md. REVISION_VERIFICATION.json records deterministic raw-trajectory and artifact checks. Internal review scores are provisional and do not predict CCDC acceptance. No navigation experiment or training was added, and no submission or push was performed.

SUPPLEMENT.md contains scientific detail using the main paper's reference numbering. EVIDENCE_INDEX.md locates frozen data and the complete recovery archive. This package is not a replacement for that full archive. The original_support directory contains copied historical checks and is not the current validation record.
