# Fig. 1 — compact visual proposal v2

Reference-protocol selection and delayed execution. (a) An active hold returns the held reference. Otherwise, an expired hold clears the incumbent before the nominal manager is called. Prediction is eligible only when review is due and a valid target is strictly within 600 m. Controller memory is replayed separately from restoring actuator setpoints from issued commands. (b) Each rollout starts with the same pending action and restored state, using a manager cloned after the nominal call. A valid, integration-successful nominal rollout with minimum margin at least ρ returns directly. Only a failed guard triggers prediction of the available continuation and four side protocols, followed by the existing ranking/fallback. Each candidate includes delivery, holding for P, and restoration of nominal feedback; predicted histories remain isolated. The old action executes first; a changed reference applies at t+1 and can first affect the interval t+1 to t+2. Physical memory is rebuilt after a reference change, and only executed feedback updates real history. Here H = 60 s, P = 15 s and ρ = 30 m.
