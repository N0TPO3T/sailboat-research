# B2 实测后的独立证据审查

日期：2026-10-08。审查节点：`/root/b2_evidence_review`；same-family provisional。分配 0 实验 worker，未拟合、训练、仿真或安装依赖；仅阅读产物并用标准库重算既有数据与评分。未修改实现、数据或主报告。本审查不以推荐选题或模拟 Accept 为目标。

## 结论

**支持本轮“尚未选中”，停止这三个候选的当前扩展。** 三个停止理由不同：F 的指定指标已接近绝对上限；I 的指定有限路线族内规划余量小，实际重构没有稳定增益；U 在修正失稳历史趋势后，所试轻量历史适配仍未出现预设量级的重构增益。不能将三者统一写成“现有方法已解决需求”。

第三题的首次完整输入原型产生了失稳模型的真实负结果；若据此否定应用，则属于伪负结论。该问题已经被诊断并最小修复；旧成绩仍可作为该失稳模型的真实失败记录，不能与传输竞态产生的无效 run 混为一类。修正版复用了已经查看的目标年份，因此仅支持探索性取舍。

## 会改变判断的问题及其处理

**1. 原历史趋势不合格，不能用其灾难性误差淘汰整个应用。** 原 `results/development_choice.json` 显示，三个 ridge 的 2020 历史 NMAE 已达 59.50–76.95，最佳 RK 仍为 9.80。`results/trend_diagnosis.json` 记录开发年 33.66% 预测触发 log 裁剪；2021 单个温度三次铰链项的最大绝对 log 贡献达 67.51。这一异常在开发年已可检测。原代码的标准化多项式与铰链特征允许很大的外推，随后指数化和 smearing 扩大线性尺度误差。该证据支持修复趋势，不支持“历史信息无用”。

修正版 `pilot_stable.py` 删除三次/铰链趋势，加入历史训练范围截断的线性 ridge、历史月/深度分层中位数和历史 IDW，以 2020 选择基础趋势，再使用相同历史趋势进行所有残差更新。掩码、评分、核集合和意义门保留。最终选择分层中位数，开发历史 NMAE 为 0.8784。该修复与观测到的失败机制对应；没有必要继续盲扫超参数。

**2. 稳定版未获得有用增量，但当前中位数也不能称为合格监测解。** 当前中位数的六单元 NMAE 为 0.672–0.871，绝对相对均值偏差为 0.407–0.679。偏差门仅限制方法相对基线进一步恶化，不保证绝对偏差足够小。领域验收阈值尚未提供。因此应说“当前方法筛选未选中，需求尚未被证明满足”，不能说“强简单法已足够”。

**3. 原型门与应用门必须分开。** 稳定版分别冻结 `current_median` 与 `history_median`，另保留 RK 对固定简单法的增量门。这一处理正确：成熟历史法本身若有足够收益，可以支持应用继续，无须要求 RK 再胜出。实际两门都未通过，且不是仅因一个微小负单元：六单元全部没有达到 0.05 的最小改善。

## 信息边界与最终取舍

离线信息流为：

```text
严格更早年份标签 → 开发选定的历史趋势 → 当年固定支持集预测
                                            ↓
当年随机整块可见标签 → 全局/分层/空间残差更新
                                            ↓
共同隐藏组真值仅用于评分 → NMAE、偏差、预设继续门
```

代码中未发现破坏上述限定任务的目标标签泄漏。当前标签预算按相同整块掩码共享，源片段数被记录；后验环境特征和实际观测时段汇总在隐藏组仍可使用，因为任务明确为离线回放。这不能解释为出航前或实时可用信息。历史同地观测允许存在，验证对象是既有监测区域年度更新；没有验证新空间泛化。每个目标年用完整更早年份，也不是连续多年均稀疏采样的部署链。

主任务按实际已观测组等权计分，既不是统一月份的均匀时间平均，也不是海域总量或生物量。原始观测片段预算不等于航程、功耗或真实采样次数减少。三个 mask 是条件于各年数据的抽样敏感性检查，不是独立海洋任务。当前资料没有提供实际监测误差容忍度，因此本轮只能完成选题筛选，不能证明任何方案已满足应用。

**不再要求第四题、大模型、更多种子或额外方法平台。** 在当前共享预算与最多三题范围内，有效结论是“前两题缺少指定尺度的增量空间；第三题的稳定轻量适配没有足够继续信号；尚未选中”。这不否定全部声学历史模型、原论文 sdmTMB 或所有真实海洋任务。未运行的其他候选仍是未判定，不能因本轮未选中而记为负结果。
