# B2 独立文献与代码机会发现

日期：2026-10-08。范围：仅读研究简报、共享预算及一手来源，未读取另外两个发现工作流。没有启动仿真、训练或实验 worker。本文件提出三个问题，不声称已有本地收益；不是最终选题。

## 判断摘要

优先廉价验证“有返航期限的风驱动海洋采样”；第二候选是“有限转向与测线几何下的帆船覆盖”；第三候选是“弱传感冗余下的故障诊断与安全降级”，先做可辨识性检查。三者分别优化观测效用、测绘覆盖和观测可信性，不能合并成一个大系统。

现有方法覆盖得比泛化标题暗示的多。不能把“GP+RRT*”“风感知覆盖”“自适应故障滤波”作为新增贡献。可继续的前提是具体部署约束下，正确适配的成熟方法仍有可测且有价值的缺口。

## L1：必须按时返航的风驱动河口采样

**需求与任务。** 河口盐度/水质采样需在回收时间前回到指定点。目标是固定截止时间内取得可用环境信息，同时报告迟归率和迟归时长。帆船去程和返程航时不对称，距离预算不能代表时间预算。应用类别由海洋采样原论文支持；本项目是否存在值得改善的迟归与信息损失，尚未验证。

**已有解决程度。** [Ge 等，2025，RRTCV](https://www.sciencedirect.com/science/article/pii/S0950705125003089)已将不确定性下降、分类目标及返航约束放入非贪心采样，并提供[作者代码与数据](https://github.com/MASCOT-NTNU/RRTCV)。不能称长视野采样为新问题。该论文摘要甚至明确说相对贪心的数值增益很小，不能从“非贪心”推断大收益。更近的[Chavez-Galaviz 等，2026](https://www.frontiersin.org/journals/robotics-and-ai/articles/10.3389/frobt.2026.1823324/full)方法节将 AK-GP 方差用于引导 Dubins-RRT*；实验比较含 greedy、GreedyCover、HEXCover，所有组共享环境模型。其第3节预算为每周期路径长度，第5.2节忽略试验内时间变化；不是已经解决风驱船全任务期限返航的证据。

**实际代码依据。** 已直接读取 `Publication/src/CostValley/Budget.py` 和 `CostValley.py`。前者每次按位置欧氏增量扣减 budget，并用当前位置/终点作为椭圆焦点构造可达区；后者沿线积分代价。源码与作者 README 的建议目录不完全一致，不能照 README 假定 `src/common` 已存在。当前只确认两个源文件语义，尚未执行，不能称端到端可复现。

**真正剩余空间（假设）。** 在同一信息模型下，用有向航时和返航可行集代替各向同性距离预算，可能减少返航失败与过早退出；这首先是成熟方法适配，不是新算法。只有再相对“航时图+保守返航余量+收益/航时贪心”有实质改善，才值得深入较复杂长视野方法。

**最强简单威胁与最小原型。** 共享相同 GP 后验和同一帆船极图，比较：(a) 有向最短航时返航约束下的收益/航时贪心；(b) 小深度 beam search 或 receding-horizon orienteering；(c) 小图全枚举 oracle，仅用于上限。欧氏版本只作诊断弱对照，不是主基线。无需先移植 ROS/Gazebo、RRT 或神经核。

**双边 pilot。** 预先构造正常/逆向返航、弱/中等流、静态/缓变风的条件族，使用12–24个成对小图任务，同一环境真值与噪声。自变量仅决策视野或返航约束表示；控制地图、极图、初始 GP、采样频率和计算预算。主指标为期限内返回且完成测量时的全域/前沿误差；另单独报告返航失败，不能删掉失败船后计算地图均值。支持信号是有向贪心仍系统性错过可达信息区域，短视野原型能改善误差且不增加迟归；若有向贪心已接近 oracle，则停止复杂规划。地图误差下降但返航更差属于不能支持。用额外采样数解释增益时，应加同样采样数/时间对照。

**资源和物理边界。** 计划单 CPU 线程、分钟至小时级小图和 GP，不需 GPU。风流场首轮可用合成族，但不能称真实海域验证。极图只给稳态速度，需至少计入换舷时间/损失及不可直航角；流影响对地航时，传感器采样只覆盖经过的位置，不能整格瞬时观测。必须先检查“总是可返航”是不是任务本身不成立。若强简单适配即成功，结论是采用它或做应用验证，不包装成算法优势。

## L2：有限转向和窄测量条带下的帆船覆盖

**需求与任务。** 声学测绘等任务需要在有限时间内覆盖区域，不能只到若干航点。主指标是由实际轨迹与传感器条带计算的覆盖时间/覆盖率，同时记录重复覆盖和转向损失。它与 L1 的信息采样不同：任务要求规定区域足够覆盖，而非自适应选择少数高价值位置。

**原论文核查。** [An 等，2026，全文](https://arxiv.org/html/2602.15901v1)已经提出帆船时空覆盖 MCTS。已读 II–IV、算法1/2、式1和6–16。其 II-A 假设格子远大于船长、格内可完成换舷、无障碍；II-B 用稳态极图与迎风速度惩罚；III 结合覆盖/耗时、形状规则和预测 rollout；IV 对照含固定扫线及不同预测视野。故“帆船+预测+覆盖”已被占据。本次未找到作者代码链接，不能声称开源或已经复现。

**剩余空间（假设）。** 当测线间距和转向尺度相近，覆盖单元中心到达与真实传感器条带覆盖可能分离。这是尺度适用性假设，不是原文方法失败事实。我们只能研究明确窄条带/有限回转条件，不能凭给仿真加难度宣称普适改进。

**成熟解先行。** 扫描方向优化+顺逆行选择+转弯可行连接是必须先试的对照；不能选任意固定扫线让它迎风失败。比较同样极图/转向约束下的优化扫线与覆盖条带任务排序（小规模 ATSP 或 beam search）。原文 MCTS 如无法准确复现，标注外部强解缺失，不能宣布超越文献。

**廉价判别。** 用3种长宽比×3种相对风向×2种测线间距/转向尺度比，先做离散航迹+条带几何，无低层重训。配对比较覆盖达到指定比例的时间、不可达转弯数、遗漏条带面积、规划时间。支持条件是优化扫线仍因反复不可执行连接或大回转付出任务级代价，简单排序能稳定消除；若仅差几个秒或调扫线方向就等效，则停止。若优势只来自忽略换舷动态/允许原地转向，整个结果作废。

**成本与边界。** 单线程 CPU；首次航迹几何检查应在1小时内完成。真实声呐视场、覆盖有效性随航速/姿态变化尚未取得参数，不应把随意圆盘当作仪器实测。可先明确为条带传感器的受限仿真。窄水域需要障碍与可行换舷模型，不能直接依赖本项目旧低层模型自动保证。

## L3：弱传感冗余下区分导航传感器故障和环境漂移

**需求与任务。** 长航时小型海洋机器人需在 GNSS/航向传感器异常时避免依据错误状态继续执行危险航迹。首要指标是规定误报率下可检测故障的检测延迟，以及故障后航迹误差/约束违反；估计 RMSE 是辅助指标。此题不承诺恢复绝对定位。

**全文证据。** [Asfihani 等，ECC 2024 原论文](https://www.paperhost.org/proceedings/controls/ECC24/files/0541.pdf)第II–III节用测量滤波、增广系统和带遗忘的自适应 KF 估计偏置；假设含可观测性与持续激励。第V节40秒、0.01秒步长仿真，Fig.3直接出现位置偏置不收敛，Fig.4速度/航向偏置收敛。这支持“不能以滤波器名义绕过辨识条件”，不支持把所有失败归咎于缺少机动。更强的[Dhyani 等，2026，原文](https://www.sciencedirect.com/science/article/pii/S0967066125004344)第2–3节已使用重叠传感器集合、观测器残差、自适应阈值和组合隔离，考虑扰动/传感配置；全文方法与结论已查。它是适用强对照，不可只比裸 EKF。

**拟议剩余空间。** 小帆船的低成本传感器缺乏独立冗余，低速时 COG 不等于航向；海流、侧滑和航向偏置可能在现有观测中不可区分。机会可能是辨识条件下的诊断/主动机动，或不可辨识时明确降级，而不是万能故障补偿。相关代码及真实故障数据本次未核实，故工程风险高于 L1/L2。

**最小 kill pilot。** 在固定传感器契约下先构造两种不同故障/环境参数产生相同观测历史的反例，并检查线性化可观测矩阵/有限差分敏感度。只有这个门通过才做闭环。候选对照为正确建模流/侧滑的 EKF+创新门限、残差多模型/观测器组，与“信息不足时停止诊断并切入预定安全策略”的最小原型。固定零故障、流阶跃、航向偏置、GNSS缓漂、短时中断等族，正常/机动航段都要覆盖；不能将环境变化标作故障训练标签再称真实检测。

**反驳与边界。** 若独立观测不足导致结构不可辨识，增加滤波器复杂度不值得继续；若标准创新门限已实现相同漏报/误报折中，停止。若轻微机动提高辨识却造成更大偏航/耗时，要把代价计入。绝对 GNSS 偏置缺外部锚点不能凭主动转向必然消除；需要新增传感器才能完成时，本轮仅记录资源缺口，不采购。先离线诊断，CPU即可；无已验证故障数据，不能支持实船可靠性 claim。
