# I：期限返航信息采样——预先协议草案

2026-10-08；在看到方法成绩前制定；实现前可作有依据的修订并记录。首批开发筛选，不是独立确认。
问题：风驱观测平台在固定回收期限内完成有价值的空间采样。主问题是正确考虑航时后，强简单采样规划是否仍有值得改善的缺口。

共同信息：有限可选采样站、共同初始场模型及过去测量、当前公开的风/流条件；首轮静态已知风流以隔离规划余量。真实场仅提供当前位置测量及评分，不读取未来/未采样值。无GPU/训练。
动作：有限站点间可航路线；需有向极图、不可直航区、有限转向/换舷损失。只能算任务级模型，不能宣称旧帆舵动力学闭环已验证。若使用近似航时，明确适用条件和数值校核。不能把直指逆风当可航动作。
任务族：至少12个预定独立场/几何与风向实例，覆盖容易和逆向返航；分紧/松期限。固定整体场误差与按时返回指标，不按结果挑选环境。误差按整次任务汇总，保留迟归任务。

强对照至少：有向返航航时约束下的边际信息增益/新增时间贪心；简单插入或2-opt路线改进。合理调节成本指数/返航余量仅用独立少量开发实例，不能看最终胜负挑配置。各方相同采样与转向成本。
原型：短视野/全路线信息采样规划，直接采用成熟orienteering结构。小图枚举或DP上界若代价可行必须加入，判断是否存在剩余空间。不得把欧氏距离弱对照作为论文主胜负来源。

主指标：共同截止时的场重构RMSE或预定归一误差（包含失败），按时返回率；另外期望积分方差、采样数、总航时、规划墙钟。共同GP模型内方差不是实际重构收益；两者分开。
意义门（建议、待实现确认）：保住按时返航的条件下，多数实例实测误差有可辨认下降；若平均下降仅在少数极端例、稳健中位改进不足一次新增有效测量所对应的量级，或强简单解与小图上界余量很小，则停止复杂规划。不得只用微小统计差异推荐。
首轮最多1个单数值线程worker、<=1 CPU小时，单pilot绝对3小时，共享24小时截止不重置。尚未授权此计划启动，协调者核对后分配worker。
来源：RRTCV代码只证实欧氏预算；Ott/Kochenderfer/Boyd2024近似序贯IPP应核读方法作为成熟原型来源，不把常规beam/GP叫原创。

## 执行前冻结细化

协调者已授权1个单数值线程CPU worker，GPU0。2026-10-08，本次运行以 protocol.json 为具体数值协议：12个固定几何/风/期限实例×2个真值核尺度=24配对任务；8候选站，初始home测量。greedy、多起点insertion+有向2opt与有限路线族穷举最优共享GP与真值。穷举仅最大化预期积分方差下降，不读取测值；不称内容自适应采样。完整方法、阈值和种子在运行前写入protocol.json。

物理修正：取消最初拟定的20s驻留，因为会暗含帆船悬停。使用温盐类理想瞬时点测量，采样额外耗时0。低于45度的对水迎风航向禁止；显式两航段换舷满足位移。转向仅按8deg/s与额外5s侧向切换计时，忽略机动位移，属于任务级航时代理而非低层动力学执行。所谓exact只在固定边路径族内最优，不是物理全局上界。有正向信号也不能直接推荐真实帆船性能。

继续门：相对insertion，所有任务按时返回，RMSE配对改善中位数>=10%，至少17/24胜，预期方差平均下降>=5%。门未过就不换种子搜索优胜；有向简单解近代理上限则停止复杂化。图固定展示seed100，不挑赢家。

计时回归修正：首批结果未把规划耗时计入deadline，验证发现贴边路线迟归。原始run留存archive_no_planning_latency，撤销其全按时结论。所有方法统一预留2秒规划预算，再用实测planning_s确认总用时；其他种子、阈值、核与方法不变。
